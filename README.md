## The Requirement

8 CFR 103.2(b)(3) requires that any foreign-language document submitted to USCIS be accompanied by:

1. A full English language translation
2. A certification from the translator that the translation is complete and accurate
3. A certification that the translator is competent to translate from the foreign language into English

Key clarifications:

- No federal or state body licenses certified translators
- There is no "USCIS-approved" translator or stamp
- Notarization is not required by USCIS
- Machine translation is not accepted for official filings
